## What GitHub Pages Is

**GitHub Pages** is a free hosting service that serves static files straight from a GitHub repository. Every time new files are pushed, they can be built and published automatically — no servers to rent, no databases to configure, no midnight outages to fix.

<Callout type="tip" title="Static means simple">
"Static" just means the files are finished before anyone visits: HTML, CSS, and JavaScript, ready to serve as-is. There is no application running behind the scenes to keep warm.
</Callout>

Lessons, tutorials, documentation, and reference material are a natural fit: they are mostly text, they change gradually, and they benefit enormously from version history — "what did this page say last month?" is a question git answers instantly.

## How Publishing Works Here

This site uses a **GitHub Actions** workflow: every change pushed to the repository triggers a build, and the finished site is published automatically.

<DidYouKnow>
Because this is a **public repository**, the site is public too — which is exactly right for a learning demo. Free GitHub Pages hosting is intended for public content. Private or sensitive material belongs elsewhere.
</DidYouKnow>

## Being Honest About Limits

<Callout type="warning" title="Know the boundaries">
GitHub Pages serves **static files only**. It cannot run a database, handle logins, process payments, or keep secrets — and it should never be given credentials or private data. When a project needs an application backend, that is a different architecture, for a different purpose.
</Callout>

This demo is exactly what it claims to be: a public showcase of how MDX content can be published to the web with a small, transparent, free toolchain.

<KeyTakeaway>
GitHub Pages hosts static files free, fast, and automatically — a perfect match for learning content that lives in a public repository and changes through version control.
</KeyTakeaway>
