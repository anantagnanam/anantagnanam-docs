## The Name

**Ananta Gnanam** — आनन्त ज्ञानम् — means **"Infinite Knowledge"**. It is the belief that learning never ends: every question answered opens a door to two more, and curiosity is the fuel that keeps the journey going.

<StorySection>
That is exactly what this site is about. A girl named Leela, a wise bird named Manjari, and a magical book named Astra — three companions on a journey through the Solar System, asking questions, sharing clues, and discovering knowledge together.
</StorySection>

## Why This Demo Site Exists

This website is a **public demonstration** of a modern, simple way to publish learning content:

- **MDX** — Markdown with reusable React components — keeps lessons easy to write and beautiful to read
- **Docusaurus** — turns that content into a fast, accessible static site
- **GitHub Pages** — hosts the finished site free, straight from the repository

The whole toolchain is visible in the repository. You can read the source of every lesson, see how components work, and even submit a fix yourself. That openness is part of the idea: knowledge should be shareable, reviewable, and improvable by anyone.

<Callout type="warning" title="A public demo">
This is a public learning demonstration — it intentionally contains no private information, credentials, or internal systems. The lessons and components here are exactly what they appear to be: a showcase of MDX and GitHub Pages for educational publishing.
</Callout>
